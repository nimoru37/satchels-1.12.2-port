# Satchels

Port of the [makamys/Satchels](https://www.curseforge.com/minecraft/mc-mods/satchels) mod for Minecraft 1.12.2

**❗ [MixinBooter](https://modrinth.com/mod/mixinbooter) required. ❗**

Some things that have been changed:
* Equipment is now visible to other players
* The /clear command clears everything, including equipped satchels and pouches
* Pouches now only allow the last 8th slot to be used when a satchel is equipped. This is to ensure that pocket slots do not extend beyond the inventory boundaries.

## About
This mod adds pouches and satchels, which act as wearable inventory upgrades. Unlike your typical backpack mod, it's seamlessly integrated into the inventory screen instead of being on a separate screen.
